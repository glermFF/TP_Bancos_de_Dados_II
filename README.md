# O Cachaceiro Viajante

### Sobre

O Cachaceiro Viajante entrega ao usuário um app de recomendação de adegas/bares ou circuitos de degustação para passar a noite rondando pela cidade dentre os locais mais bem avaliados pelos usuários. 

As recomendações funcionam utilizando o conceito de nós e arestas em um grafo, onde cada nó é um bar e o peso da aresta se dá pelo nível de avaliações daquele bar em relação a distância do usuário. Como o foco é no cliente final, implementamos um sistema de recomendação que se modela de acordo com as preferências de bar do usuário, criando um circuito personalizado. 

Aos usuários cadastrados, entregamos a opção de adicionar novos bares não listados pelo app, criando novas opções aos degustadores de destilados.
